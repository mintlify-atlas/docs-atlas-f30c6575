The twilio-ruby gem is the official Ruby helper library for the Twilio platform. It gives you a clean, idiomatic Ruby interface to the full Twilio REST API, lets you generate TwiML responses to control calls and messages, create JWT access tokens for client-side SDKs, and validate incoming webhook requests from Twilio.

## Get started in minutes

<Steps>
  <Step title="Install the gem">
    Add `gem 'twilio-ruby', '~> 7.10.5'` to your Gemfile and run `bundle install`.
  </Step>
  <Step title="Get your credentials">
    Find your Account SID and Auth Token in the [Twilio Console](https://console.twilio.com).
  </Step>
  <Step title="Initialize the client">
    ```ruby
    require 'twilio-ruby'

    client = Twilio::REST::Client.new('ACxxxxx', 'your_auth_token')
    ```
  </Step>
  <Step title="Make your first API call">
    ```ruby
    message = client.messages.create(
      from: '+15005550006',
      to: '+14155551234',
      body: 'Hello from twilio-ruby!'
    )
    puts message.sid
    ```
  </Step>
</Steps>

<Note>
  Store your credentials in environment variables — never hardcode them in source code. See [Authentication](/usage/authentication) for best practices.
</Note>
