`twilio-ruby` is the official Ruby helper library for the Twilio platform. It wraps the Twilio REST API in an idiomatic Ruby interface, so you can send SMS and MMS messages, make and receive voice calls, generate TwiML responses for webhooks, create JWT tokens for client-side authentication, and validate that inbound webhook requests genuinely come from Twilio — all without writing a line of raw HTTP code. The gem is published on RubyGems and supports MRI Ruby 2.4 through 3.2 as well as JRuby 9.2 through 9.4.

## Project structure

The gem is organised into four top-level namespaces, each with a distinct responsibility:

### `Twilio::REST::Client`

The primary entry point for all API interactions. You initialise it once with your Account SID and Auth Token (or API Key credentials), and it exposes every Twilio resource as a chained method call:

```ruby
require 'twilio-ruby'

@client = Twilio::REST::Client.new(account_sid, auth_token)

# Send a message
@client.messages.create(from: '+15005550006', to: '+12345678901', body: 'Hello!')

# Make a call
@client.calls.create(from: '+14159341234', to: '+16105557069', url: 'http://example.com')
```

### `Twilio::TwiML`

Classes for generating TwiML documents that control how Twilio handles calls and messages. `Twilio::TwiML::VoiceResponse` and `Twilio::TwiML::MessagingResponse` each provide a block-based DSL that serialises to valid XML:

```ruby
response = Twilio::TwiML::VoiceResponse.new do |r|
  r.say(message: 'hello there', voice: 'alice')
  r.dial(caller_id: '+14159992222') do |d|
    d.client 'jenny'
  end
end

puts response.to_s
```

### `Twilio::JWT`

Helpers for producing signed JSON Web Tokens used by Twilio Client SDKs and other services. `Twilio::JWT::ClientCapability` handles legacy Capability Tokens; `Twilio::JWT::AccessToken` covers the newer grants-based tokens used by Programmable Video, Chat, and Voice.

### `Twilio::Security`

Contains `Twilio::Security::RequestValidator`, which verifies the `X-Twilio-Signature` header on incoming webhook requests. A Rack middleware wrapper is also loaded automatically when Rack is present, enabling signature validation as a standard middleware in Rails, Sinatra, and other Rack-based apps.

## How the library is loaded

When you `require 'twilio-ruby'`, the main entry point at `lib/twilio-ruby.rb` loads the framework layer, sets up autoloads for `Twilio::JWT`, `Twilio::TwiML`, `Twilio::HTTP`, and `Twilio::REST`, and registers the Rack middleware if Rack is already loaded. The REST client and all service-specific classes are generated from the Twilio OpenAPI spec, so the library surface always matches the API.
