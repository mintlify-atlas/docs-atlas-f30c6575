---
title: "Install twilio-ruby"
description: "Install the twilio-ruby gem using Bundler or RubyGems. Covers version pinning, Ruby version requirements, and verifying your installation."
---

`twilio-ruby` is distributed as a standard RubyGem and can be added to any Ruby project in minutes. The recommended approach is Bundler, which pins the version in your `Gemfile.lock` and ensures reproducible installs across environments. If you prefer a standalone installation without a Gemfile, RubyGems works equally well. The gemspec requires Ruby `>= 2.0.0`, and the library is actively tested on Ruby 2.4–3.2 and JRuby 9.2–9.4.

## Install with Bundler

<Steps>
  <Step title="Add the gem to your Gemfile">
    Open your project's `Gemfile` and add the following line. The pessimistic version constraint (`~> 7.10.5`) allows patch-level updates while protecting you from breaking minor-version changes:

    ```ruby
    gem 'twilio-ruby', '~> 7.10.5'
    ```
  </Step>
  <Step title="Run bundle install">
    Install the gem and its dependencies:

    ```bash
    bundle install
    ```

    Bundler resolves and locks all dependencies — including `faraday`, `jwt`, and `nokogiri` — into `Gemfile.lock`.
  </Step>
  <Step title="Require the library">
    In your application code, require the gem:

    ```ruby
    require 'twilio-ruby'
    ```

    If you are using Bundler's auto-require feature (common in Rails), this step may be handled for you automatically.
  </Step>
</Steps>

## Install with RubyGems

If you are not using Bundler, install the gem directly from the command line:

```bash
gem install twilio-ruby -v 7.10.5
```

<Note>
  If your system Ruby installation requires elevated privileges, the command may fail with a `Permission Denied` error. Prefix with `sudo` to resolve it:

  ```bash
  sudo gem install twilio-ruby -v 7.10.5
  ```

  Using a Ruby version manager such as rbenv or RVM avoids the need for `sudo` entirely, which is the recommended approach for development machines.
</Note>

## Build from source

To use the latest unreleased code from the `main` branch, build and install the gem from source:

```bash
git clone git@github.com:twilio/twilio-ruby.git
cd twilio-ruby
make install
```

<Warning>
  Source builds are not recommended for production. The `main` branch may contain incomplete features or breaking changes that have not yet been released to RubyGems.
</Warning>

## Ruby version requirements

The gemspec declares `spec.required_ruby_version = '>= 2.0.0'`. The following Ruby versions are actively tested in CI and recommended for production use:

| Implementation | Supported versions |
|---|---|
| MRI Ruby | 2.4, 2.5, 2.6, 2.7, 3.0, 3.1, 3.2 |
| JRuby | 9.2, 9.3, 9.4 |

The gem depends on `faraday` (HTTP), `jwt` (token signing), and `nokogiri` (TwiML XML). These are pulled in automatically when you install `twilio-ruby`.

## Verify your installation

After installing, confirm everything is working by sending a test SMS. Replace the placeholder values with your [Twilio Console](https://console.twilio.com) credentials and phone numbers:

```ruby
require 'twilio-ruby'

# Your Account SID and Auth Token from console.twilio.com
account_sid = 'ACXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX'
auth_token  = 'your_auth_token'

@client = Twilio::REST::Client.new(account_sid, auth_token)

message = @client.messages.create(
  body: 'Hello from Ruby',
  to:   '+12345678901',   # Your phone number
  from: '+15005550006'    # A valid Twilio number from your account
)

puts message.sid
```

If the installation is successful, the script prints a message SID such as `SMxxxxxxxxxxxxxxxxxxxxxxxxxxxx`. If you see a `LoadError`, double-check that the gem installed into the correct Ruby environment (the one your script is running with).

<Tip>
  Store your Account SID and Auth Token in environment variables rather than hardcoding them. See the [quickstart](/quickstart) for the recommended pattern using `ENV`.
</Tip>
