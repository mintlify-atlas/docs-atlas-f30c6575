This guide walks you through sending your first SMS with the `twilio-ruby` gem. You will initialise the REST client with your Twilio credentials, create a message resource, and confirm delivery by printing the message SID. The whole thing takes under five minutes if you already have a Twilio account and a verified phone number.

## Prerequisites

Before you begin, make sure you have the following:

- A [Twilio account](https://www.twilio.com/try-twilio). The free trial tier is sufficient for this guide.
- A Twilio phone number with SMS capability. You can provision one from the [Twilio Console](https://console.twilio.com).
- Your **Account SID** and **Auth Token**, both available on the [Console dashboard](https://console.twilio.com).
- Ruby 2.4 or later (MRI or JRuby 9.2+).
- The `twilio-ruby` gem installed. If you have not done this yet, see [Install twilio-ruby](/installation).

## Send your first SMS

<Steps>
  <Step title="Install the gem">
    Add `twilio-ruby` to your `Gemfile` and run `bundle install`, or install it directly:

    ```bash
    gem install twilio-ruby -v 7.10.5
    ```
  </Step>

  <Step title="Load your credentials from environment variables">
    Store your Account SID and Auth Token as environment variables so you never commit secrets to source control:

    ```bash
    export TWILIO_ACCOUNT_SID="ACXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX"
    export TWILIO_AUTH_TOKEN="your_auth_token"
    ```

    Read them in Ruby with `ENV`:

    ```ruby
    account_sid = ENV['TWILIO_ACCOUNT_SID']
    auth_token  = ENV['TWILIO_AUTH_TOKEN']
    ```

    <Warning>
      It is okay to hardcode credentials when testing locally, but use environment variables before committing any code or deploying to production. Leaked credentials can be used to place calls and send messages at your expense.
    </Warning>
  </Step>

  <Step title="Initialise the client">
    Require the gem and create a `Twilio::REST::Client` instance with your credentials:

    ```ruby
    require 'twilio-ruby'

    account_sid = ENV['TWILIO_ACCOUNT_SID']
    auth_token  = ENV['TWILIO_AUTH_TOKEN']

    @client = Twilio::REST::Client.new(account_sid, auth_token)
    ```

    The client is stateless and thread-safe. You can create it once at application startup and reuse it across requests.
  </Step>

  <Step title="Send an SMS">
    Call `@client.messages.create` with a `from` number (your Twilio number), a `to` number, and a `body`:

    ```ruby
    message = @client.messages.create(
      body: 'Hello from Ruby',
      to:   '+12345678901',   # Replace with your phone number
      from: '+15005550006'    # Replace with your Twilio number
    )

    puts message.sid
    ```

    A successful call returns a message instance. Printing `message.sid` confirms the message was queued — you should receive it on your phone within seconds.
  </Step>
</Steps>

## Full working example

Here is the complete script from the README, ready to copy and run:

```ruby
require "twilio-ruby"

# Your Account SID and Auth Token from console.twilio.com
account_sid = "ACXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX"
auth_token = "your_auth_token"

@client = Twilio::REST::Client.new account_sid, auth_token
message = @client.messages.create(
  body: "Hello from Ruby",
  to: "+12345678901",  # Text this number
  from: "+15005550006", # From a valid Twilio number
)

puts message.sid
```

<Note>
  During a free trial, you can only send messages to phone numbers you have verified in the Twilio Console. Upgrade your account to remove this restriction.
</Note>

## Using environment variables (recommended pattern)

The pattern below keeps secrets out of your source files and works in any environment — local development, CI, or production:

```ruby
require 'twilio-ruby'

@client = Twilio::REST::Client.new(
  ENV['TWILIO_ACCOUNT_SID'],
  ENV['TWILIO_AUTH_TOKEN']
)

message = @client.messages.create(
  body: 'Hello from Ruby',
  to:   ENV['MY_PHONE_NUMBER'],
  from: ENV['TWILIO_PHONE_NUMBER']
)

puts message.sid
```

Set the variables in your shell, a `.env` file loaded by a gem like `dotenv`, or your deployment platform's secret store.

## Confirm it worked

When the `create` call succeeds, `message.sid` contains a string that starts with `SM` — for example, `SM1234567890abcdef1234567890abcdef`. You can look up this SID in the [Twilio Console Message Log](https://console.twilio.com/us1/monitor/logs/sms) to see delivery status, error codes, and more.

<Tip>
  Add error handling so your application responds gracefully to API errors. Twilio returns a `Twilio::REST::RestError` for 4xx and 5xx responses:

  ```ruby
  begin
    message = @client.messages.create(body: 'Hello!', to: '+12345678901', from: '+15005550006')
    puts message.sid
  rescue Twilio::REST::RestError => e
    puts e.message
  end
  ```
</Tip>
